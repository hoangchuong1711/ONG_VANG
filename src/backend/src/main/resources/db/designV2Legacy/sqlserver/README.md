# Lịch sử tương thích V1–V26

Các file được chuyển nguyên trạng từ DesignV2 trước khi gộp, chỉ dùng với DB có V1 `V1__create_business_tables.sql` trong lịch sử Flyway. Không sửa nội dung hoặc checksum. DB mới dùng `db/designV2/sqlserver/`.

Thư mục này phải nằm trong bản đóng gói để backend có thể validate và tiếp tục DB cũ mà không xóa dữ liệu hay sửa history.
